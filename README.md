# pol-nippon Memory

A memory-matching card game for learning Japanese vocabulary through Polish, built with Python and pygame.

Flip cards to find matching pairs — each pair links a Japanese word to its Polish translation, covering everyday phrases, food, and culture (こんにちは / Dzień dobry, 寿司 / sushi, and more). Match every pair to win.

## Running the game

```bash
pip install -r requirements.txt
python main.py
```

Use `--pairs` to change the board size:

```bash
python main.py --pairs 12
```
